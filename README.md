# vtanixdevkid.github.io

Welcome to **vtanixdevkid.github.io**, my personal website.
This isn’t just some empty page or a copy-paste template. This is where I learn, experiment, and slowly build my web dev skills from scratch.

This website exists so I can:

* learn HTML, CSS, and JavaScript
* try random ideas (some work, some totally don’t)
* track my progress and see how far I’ve come

I’m still a **beginner**, and yeah, that’s fine.
The code here might not be perfect, not super clean, and sometimes a bit messy. But everything is written by me. I spent time thinking, testing, breaking things, fixing them, breaking them again, until it finally worked. And honestly, that alone took a lot of effort.

### About using this code

This repo is **open source**, but that doesn’t mean “free to steal.”
Please respect the work behind it.
You’re welcome to learn from it or take inspiration, but **don’t straight-up copy it without permission**, and definitely don’t claim it as your own. That’s just lame.
